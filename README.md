# mekotools/ganlab

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Hier liegt keine eigene
Software: Das fertige Container-Abbild wird über diesen Workflow veröffentlicht,
damit es auf gemieteten GPU-Instanzen (vast.ai) **ohne Anmeldung** gezogen
werden kann.

- Werkzeug: GAN Lab — GANs interaktiv trainieren (poloclub)
- Bezug: `docker pull ghcr.io/mekotools/ganlab:latest`
- Projekt: MekoTools — Medienkompetenz-Werkzeuge für Lehrkräfte

Das Bau-Rezept liegt im internen Repo; hier steht nur das veröffentlichte
Ergebnis samt Zuliefer-Workflow.
